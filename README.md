# 🎂 Happy Birthday! ✨

An interactive, heartfelt birthday celebration web application built with **React 19**, **TypeScript**, and **Vite**.

## ✨ Features

- 🕯️ **Interactive Candle Blowing**: Tap/click each candle on the cake to blow it out, accompanied by realistic flame extinguishing and smoke animations.
- 🎊 **Celebration Confetti**: Trigger a colorful confetti explosion and heart glows once all candles are extinguished.
- 💌 **Animated Heart-Sealed Letter**: An elegant letter envelope with a heart wax seal that opens to reveal a sincere, heartfelt birthday message.
- ✨ **Ambient Visual Effects**: Floating background sparkles and glowing stage lighting for an immersive experience.
- 🔁 **Relight & Replay**: Easily relight the candles with one click to celebrate again.
- 📱 **Mobile & Desktop Responsive**: Optimized for smooth animations and delightful interactions across all screen sizes.

## 🛠️ Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18+ recommended) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Lawrencejay22/Happy_birthday.git
   cd Happy_birthday
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deploy to Vercel

### Option 1: One-Click Import via Vercel Dashboard (Recommended)

1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and import **`Lawrencejay22/Happy_birthday`**.
3. Keep the default settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.

### Option 2: Deploy using Vercel CLI

```bash
# Install Vercel CLI globally (if not installed)
npm install -g vercel

# Log in and deploy
vercel
```
